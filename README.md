# Aadhaar-Enrollment-Analysis
Data analytics project exploring Aadhaar enrollment data using Python. Includes data cleaning, exploratory data analysis (EDA), feature engineering, and actionable insights to identify enrollment trends across demographics and regions.
# 📊 Aadhaar Enrollment Analysis

## 📌 Project Overview

This project performs an Exploratory Data Analysis (EDA) on the Aadhaar Enrollment dataset using Python. The aim is to analyze enrollment patterns across districts, age groups, and pincodes to identify meaningful trends and insights.

The project demonstrates data cleaning, preprocessing, visualization, and insight generation using Python's data analysis libraries.

---

## 🎯 Objectives

- Clean and preprocess the Aadhaar enrollment dataset.
- Perform exploratory data analysis (EDA).
- Analyze enrollment distribution across districts.
- Study enrollment by age groups.
- Identify the top performing pincodes.
- Generate meaningful insights using visualizations.

---

## 🛠️ Tech Stack

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

---

## 📂 Dataset

The dataset contains Aadhaar enrollment records with information such as:

- District
- Pincode
- Age Group
- Total Enrollment
- Other demographic details

# 🔍 Key Insights

- Pune recorded the highest Aadhaar enrollment among all districts in the dataset.
- The **0–5 Years** age group contributed the largest share of enrollments.
- Enrollment decreases significantly for the **18+ Years** category.
- A small number of pincodes account for a large proportion of total enrollments.
